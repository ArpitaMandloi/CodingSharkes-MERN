Array Practice Questions

1. Reverse an Array
Write a function to reverse an array without using built-in methods.
Example:
Input: [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]

2. Find the Second Largest Number
Write a function to find the second-largest number in an array.
Example:
Input: [10, 20, 30, 40]
Output: 30

3. Remove Duplicates
Write a function to remove duplicate elements from an array.
Example:
Input: [1, 2, 2, 3, 4, 4, 5]
Output: [1, 2, 3, 4, 5]

4. Rotate an Array
Write a function to rotate an array n times to the right.
Example:
Input: [1, 2, 3, 4, 5], n = 2
Output: [4, 5, 1, 2, 3]

5. Find Missing Numbers in a Range
Given an array of unique numbers within a range, find all missing numbers.
Example:
Input: [1, 3, 4, 7], Range: 1-7
Output: [2, 5, 6]
